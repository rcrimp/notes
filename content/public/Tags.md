# Tags
- Double down on the punchline. Have at least 2 extra punchlines
- Don’t beat a dead horse, each punchline should be different
- Build the joke, elaborate, make it more ridiculous, more extreme, more absurd
- Push yourself as a writer, force yourself to write 2 toppers.
- Snowball laughter, rolling laughter

> You’re always one punchline away from having gold-Brendhan Lovegrove
