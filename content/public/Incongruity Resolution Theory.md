# Incongruity Resolution Theory
Brian Boyd (2004) from seriousness to play

Incongruity resolution theory is best described with the following joke

Software testers joke

The setup (S) is a question which contains a presupposition that software testers have many children. This proposition feels *incongruent* with reality. It could feel congruent to propose that Mormons have many children, but no such stereotype exists for software testers, so the listener justifiably doubts the proposition. In the punchline (P) the incongruity is resolved (with faulty logic) and the listener now understands the setup. The verb "reproduce" can be applied to both software bugs and children, and the category error of "software bugs" and "children" both being "mistakes" of the same kind.

The resolution of the incongruity could be faulty logic like above, however a logical connections are possible.

> another example.

Freud's [Relief Theory](public/Relief%20Theory.md) is similar, except Relief Theory is described in terms of social tension resolving into release of tension. Incongruity resolution is confusion to coherence.
