## Glossary

- Sketch
- Scene = Game + Plot
- Plot
- Game - the funny, pattern recognition + repeat, escalate
- Base Reality - explore: who, what, where
- Yes-And
	- explore base reality, additional details
- FUT First Unusual Thing
	- [Foregrounding](public/Foregrounding.md) against base-reality
- If-Then - game moves, repeat unusual thing into a pattern
- Framing - identify FUT, exclamation, question, honest reaction, etc. 1st game move
- Scenes Types
	- Organic Scenes - players discover FUT through yes-and
	- Premise Scenes - provided FUT. Skipping yes-and, still requires a player to frame the game
- playing to the top of your intelligence improv
- the flash
- Agreement: character vs player
- crazy town: too many unusual things, unfocused gameplay
- Character
	- grounded reaction
	- Filters - reactions filtered through character/environment
	- status - 
	- [character motivation for improv](public/character%20motivation%20for%20improv.md)
- initiation
	- first line of a scene
	- start the scene, in the middle of things
- object work - mimed interactions
	- chairs
- object
- chaff - ???
- heightening
- bad initiation
	- breaking the pattern
	- ie reversing the already funny thing
- steamrolling
	- not listening
	- ignoring scene partners
- commitment - good actors disappear into their roles
- detachment - not committing, unintentional or ironic
- commenting - ironic detachment
