- Jokes have structure, a linguistic shape
	- Some people say *"there are only 5 types of jokes"*
		- In a derisive way, as if it's a triviality.
		- but there are only 26 alphabet letters
		- and there are only 12 musical notes
	- one can reduce anything down into a finite set
		- but if you learn what they are and how to use them
		- you can write a symphony 🎶
- The goal of this project:
	- Build an encyclopedia of joke structures
