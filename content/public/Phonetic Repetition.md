### Effect
The greater the semantic distance between words, the greater the effect.

| Rhyme | Effect |
| :----- | :----------------- |
| 'pair' and 'pear' | none |
| 'Essex' and 'Wessex' | weak |
| 'potato' and 'chateau' | strong |
| 'Goat fondue' and 'tiramisu' | funny |

(swiss cheese, italian dessert)
big semantic distance + little phonetic distance = incongruity
